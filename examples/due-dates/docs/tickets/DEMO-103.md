# DEMO-103: A report of the samples due soon

An invented ticket, for this demo.

## What is asked

Each morning the lab wants a list of the samples due today, the next working
day, and within a few days after that, soonest first, with the instrument
each one needs.

## What done looks like

- [x] The list has every sample due in the window and none outside it.
- [x] Each row says whether the sample is due today, the next working day, or soon.
- [ ] A sample whose due date has passed is marked late.

## Notes

- Marking late samples is not built yet: see the spec.
